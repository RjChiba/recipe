# recipe
お料理のレシピです。誰でもレシピを追加・修正できます。

## ディレクトリ構成

レシピは `recipes/` 以下に、料理名をそのままディレクトリ名にして管理します。

```
recipe/
└── recipes/
    ├── tsuna-kyu-tofu/   # ツナきゅうり豆腐
    │   └── recipe.md
    └── ...
```

## レシピの追加・修正

### ブランチ命名規則

```
add/<料理名>      # 新しいレシピを追加する場合
fix/<料理名>      # 既存のレシピを修正する場合
```

例: `add/tsuna-kyu-tofu`、`fix/tsuna-kyu-tofu`

### PR の出し方

1. このリポジトリをフォークする
2. 上記の命名規則でブランチを作成する
3. レシピを追加・修正する
4. PR を作成する

### PR に書くこと

- **何の料理か**（料理名・ジャンル）
- **どんな変更をしたか**（新規追加 / 分量修正 / 手順の明確化 など）
- あれば **一言コメント**（アレンジのポイント、食べた感想など）

### レシピのフォーマット

各レシピディレクトリに `recipe.md` を置いてください。内容は自由ですが、以下を目安にしてください。

```markdown
# 料理名

## 材料（〇人前）

- 食材A: 〇g
- ...

## 作り方

1. 手順1
2. ...

## メモ

ポイントや保存方法など（任意）
```
